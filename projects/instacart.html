Instacart Cross-Sell & Bundle Strategy

This project uses Instacart market basket data to understand product relationships, reorder behaviour, and opportunities for cross-sell and bundle strategy. The project combines SQL Server data warehousing with Power BI reporting to create a business-ready analytics solution.

Business Problem

Grocery platforms need to understand which products are frequently purchased together, how reorder behaviour develops over time, and which departments drive repeat purchasing. Without a reliable data model, these questions are difficult to answer at scale.

Key Questions

  • Which departments and products dominate basket behaviour?
  • How does reorder behaviour change across customer order history?
  • Which product combinations create strong cross-sell opportunities?
  • How can the data be structured for reliable Power BI analysis?

Data & Tools

  • Dataset: Instacart orders, products, departments, aisles, and reorder behaviour
  • Scale: approximately 3.4M orders and 33M order-product rows
  • Tools: SQL Server, T-SQL, Power BI, DAX, Python
  • Techniques: dimensional modelling, ETL validation, star schema design, basket analysis, Power BI reporting

Approach

  1. Cleaned raw CSV data and prepared it for SQL Server loading.
  2. Created raw, staging/cleaning, and data warehouse layers.
  3. Designed a Kimball-style star schema with fact and dimension tables.
  4. Loaded fact and dimension tables using surrogate keys.
  5. Built validation checks to confirm row counts, key integrity, and data quality.
  6. Created analytical SQL views and Power BI visuals for business interpretation.

Key Insights

  • Produce and dairy/eggs showed strong co-purchase behaviour, making them suitable for bundle strategy.
  • The 5th order was identified as a loyalty inflection point.
  • Reorder behaviour became more meaningful as customers placed more orders.
  • A proper SQL warehouse made the Power BI model cleaner, faster, and easier to validate.

Business Recommendations

  • Use frequently co-purchased departments to design bundle promotions.
  • Target customers around key loyalty inflection points with reorder-based recommendations.
  • Use department-level reorder rate to prioritise merchandising and recommendation strategies.
  • Maintain a reusable dimensional model for scalable BI reporting.

Project Value

This project demonstrates my ability to build the full analytics pipeline: raw data preparation, SQL warehousing, validation, business queries, Power BI modelling, and insight communication.
